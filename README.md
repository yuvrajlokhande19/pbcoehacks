## 🚀 About PBCOEHacks 2027

**PBCOEHacks 2027** is an intensive 24-hour national physical hackathon hosted at Priyadarshini Bhagwati College of Engineering (PBCOE), Harpur Nagar, Umred Road, Nagpur, Maharashtra - 440024.

- ⏱️ **Duration:** 24 Hours continuous non-stop building
- 👥 **Hackers:** 200+ Pan-India undergraduate & engineering students
- 💰 **Prize Pool:** ₹1,00,000+ in cash prizes, trophies, hardware dev kits, and incubation grants
- 🆓 **Cost:** **100% Free** for all external students (5 meals, overnight accommodation, hardware loaners, swag boxes, and travel stipends provided)

## 📦 Zero-Build Deployment

The site is built as a single, self-contained `index.html` file using:
- **Tailwind CSS** (via CDN)
- **Lucide Icons** (via CDN)
- **Google Fonts (Outfit & Inter)**
- Native Vanilla JavaScript for countdown timer, interactive tabs, responsive mobile menu, particle canvas, and FAQ accordion.

No Node.js, npm, or build dependencies are required. It deploys instantly on GitHub Pages.
